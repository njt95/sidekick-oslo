Try this order:

Tap through sign-up. Any numbers work for now.
Tap Maja’s run, then “Request to join”. Use the dashed demo box to pretend to be Maja. “Picks someone else” shows what a declined person sees: “This activity is full”.
Go to the Post tab, write a plan, and post it. Three people ask to join. Decline one, accept another, and you get a match.
